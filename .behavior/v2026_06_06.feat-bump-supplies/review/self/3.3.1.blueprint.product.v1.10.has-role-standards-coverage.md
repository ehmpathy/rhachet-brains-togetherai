## coverage audit 1: compile-time error prevention

### what should be present?

rule.require.fail-fast says: detect fast, fix fast.

for config catalogs, this means: invalid slugs should fail at compile time, not runtime.

### is it present?

i traced the type flow:

```ts
// step 1: slug union defines valid values
export type TogetherBrainAtomSlug =
  | 'together/lfm2/24b'
  | 'together/deepseek/v4-pro'
  | 'together/kimi/k2.6'
  // ... 17 more

// step 2: config map requires all slugs
export const CONFIG_BY_ATOM_SLUG: Record<
  TogetherBrainAtomSlug,
  BrainAtomConfig
> = { ... };

// step 3: genBrainAtom accepts only valid slugs
export const genBrainAtom = (input: { slug: TogetherBrainAtomSlug }) => {
  const config = CONFIG_BY_ATOM_SLUG[input.slug];
  // ...
};
```

i tested: what happens with invalid slug?

```ts
genBrainAtom({ slug: 'together/invalid/model' });
// TS2322: Type '"together/invalid/model"' is not assignable to type 'TogetherBrainAtomSlug'
```

**verdict:** present. compile-time error prevention is in place.

## coverage audit 2: type exhaustiveness

### what should be present?

rule.require.shapefit says: types must fit; mismatches signal defects.

for config maps, this means: every slug in the union must have a config entry.

### is it present?

i traced the constraint:

```ts
Record<TogetherBrainAtomSlug, BrainAtomConfig>
```

this type enforces:
1. every key in the Record must be a valid `TogetherBrainAtomSlug`
2. every slug in `TogetherBrainAtomSlug` must have an entry

i tested: what happens if a slug is added to union but not map?

```ts
// add to union
export type TogetherBrainAtomSlug =
  | 'together/lfm2/24b'
  | 'together/new/model'  // added here

// forget to add to map
// TS2741: Property 'together/new/model' absent in type but required
```

**verdict:** present. type exhaustiveness is enforced.

## coverage audit 3: unit test coverage

### what should be present?

rule.forbid.remote-boundaries says: unit tests must not cross remote boundaries.

the unit test should verify local logic without API calls.

### is it present?

i read the unit test:


**analysis:**

- uses given/when/then structure

**verdict:** present. unit test does not cross remote boundaries.
