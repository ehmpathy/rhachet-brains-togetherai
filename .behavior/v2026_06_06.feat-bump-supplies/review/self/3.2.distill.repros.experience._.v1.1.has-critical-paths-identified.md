# review.self: has-critical-paths-identified

## critical paths

### path 1: genBrainAtom({ slug })

**why critical:** primary entry point for all consumers. every developer who wants to use a together.ai model starts here.

**what if this path fails?**
- developer cannot instantiate brain atoms
- entire library becomes unusable
- no fallback exists

**pit of success review:**

| check | status | articulation |
|-------|--------|--------------|
| narrower inputs | ✓ | `TogetherBrainAtomSlug` type union constrains to valid slugs only. typescript catches typos at compile time. |
| convenient | ✓ | single object `{ slug }` - no config, no api keys at this layer, no options. one input, one output. |
| expressive | ✓ | slug encodes family/model hierarchy (e.g., `together/deepseek/v4-pro`). readable and self-descriptive. |
| failsafes | ✓ | invalid slug fails at compile time. runtime lookup returns from CONFIG_BY_ATOM_SLUG or throws. |
| failfasts | ✓ | if slug somehow bypasses types, `CONFIG_BY_ATOM_SLUG[slug]` throws immediately on undefined access. |
| idempotency | ✓ | pure function. same slug always returns identical BrainAtom. safe to call multiple times. |

### path 2: getBrainAtomsByTogetherAI()

**why critical:** discovery of all available atoms. developers use this to explore the catalog, find models by spec, or build selection UIs.

**what if this path fails?**
- developer cannot discover available models
- must hardcode slugs without exploration
- no way to iterate over catalog programmatically

**pit of success review:**

| check | status | articulation |
|-------|--------|--------------|
| narrower inputs | ✓ | zero inputs required. no configuration, no filters, no options. |
| convenient | ✓ | returns complete array of BrainAtom instances, ready to use or inspect. |
| failsafes | ✓ | always returns array, never null or undefined. empty array impossible due to hardcoded slugs. |
| idempotency | ✓ | pure function. same call always returns same 20 atoms in same order. |

## non-issues articulated

1. **type union ensures compile-time validation**
   - why it holds: typescript rejects unknown slugs before code runs
   - tested: unit test confirms 20 atoms, types would fail if mismatch

2. **config map ensures runtime lookup**
   - why it holds: CONFIG_BY_ATOM_SLUG is exhaustive over TogetherBrainAtomSlug
   - tested: genBrainAtom unit test verifies lookup succeeds for all slugs

3. **both paths tested in unit tests**
   - why it holds: index.unit.test.ts covers getBrainAtomsByTogetherAI (20 atoms)
   - why it holds: genBrainAtom tested via slug parameter validation
