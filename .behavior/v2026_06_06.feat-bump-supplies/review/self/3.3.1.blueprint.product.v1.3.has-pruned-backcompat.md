# review.self: has-pruned-backcompat

## the review

i opened the blueprint. i looked for backwards compatibility concerns.

for each, i asked: did the wisher request this? is there evidence?

---

## backwards compat concerns found

### concern 1: extant slug preservation

**the concern:** we did not remove any extant slugs.

**did the wisher explicitly request this?**
- no: wish says "append the latest models"
- no explicit request to preserve extant slugs

**is there evidence this backwards compat is needed?**
- yes: semver contract
- removal of extant slugs is a contract break
- consumers depend on `together/qwen3/coder-next` etc.
- removal would require major version bump

**or did we assume it "to be safe"?**
- this is not safety assumption
- this is standard additive change practice
- wish says "append" not "replace"

**verdict:** keep. standard semver. wish says "append."

---
