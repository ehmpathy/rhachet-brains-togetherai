# review.self: has-consistent-conventions

## the review

i opened BrainAtom.config.ts. i studied extant name patterns.

i asked: do new names follow extant conventions?

---

## extant conventions identified

### convention 1: slug pattern

**extant pattern observed:**

```ts
'together/qwen3/coder-next'    // together/{family}/{variant}
'together/llama3.3/70b'        // together/{family}/{size}
'together/deepseek/r1'         // together/{family}/{variant}
'together/glm/4.7'             // together/{family}/{version}
```

**pattern:** `together/{family}/{identifier}`

where identifier is one of:
- variant name (coder-next, r1)
- size (70b)
- version (4.7)

### convention 2: description pattern

**extant pattern observed:**

```ts
'Qwen3-Coder-Next - optimized for agentic code (262K)'
'Llama-3.3-70B - largest llama model (128K)'
'DeepSeek-R1 - reason model (128K)'
```

**pattern:** `{ModelName} - {capability} ({context}K)`

### convention 3: model ID pattern

**extant pattern observed:**

```ts
model: 'Qwen/Qwen3-Coder-Next',
model: 'meta-llama/Llama-3.3-70B-Instruct-Turbo',
model: 'deepseek-ai/DeepSeek-R1',
```

**pattern:** `{org}/{ModelName}` (from together.ai)
