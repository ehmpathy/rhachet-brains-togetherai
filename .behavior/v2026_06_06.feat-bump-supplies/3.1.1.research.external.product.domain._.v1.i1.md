### literals

#### BrainAtomConfig

```ts
type BrainAtomConfig = {
  model: string;        // api model id (e.g., 'Qwen/Qwen3.5-9B')
  description: string;  // human-readable description
  spec: BrainSpec;      // cost and capability specification
}
```

source: internal code [1]

#### BrainSpec

```ts
class BrainSpec {
  cost: {
    time: { speed, latency };
    cash: { per, cache, input, output };
  };
  gain: {
    size: { context: { tokens } };
    grades: { swe?: number };
    cutoff: string;
    domain: 'SOFTWARE' | 'ALL';
    skills: { tooluse: boolean };
  };
}
```

source: rhachet package [2]

---

#### TogetherBrainAtomSlug

union type of valid model slugs in format `together/{org}/{model}`:

```ts
type TogetherBrainAtomSlug =
  | 'together/qwen3/coder-next'
  | 'together/deepseek/v4-pro'
  | 'together/lfm2/24b'
  // ... etc
```

source: internal code [1]

## composition for wish

1. user imports `genBrainAtom`
2. user passes slug string
3. typescript validates slug against union type
4. `genBrainAtom` looks up config from `CONFIG_BY_ATOM_SLUG`
5. config contains model ID and BrainSpec
6. BrainAtom instantiated with spec
7. user receives typed brain ready for inference
