# 3.2.distill.repros.experience

## experience reproductions

| experience | entry point | user actions | expected outcome | test type |
|------------|-------------|--------------|------------------|-----------|
| select model by slug | `genBrainAtom({ slug })` | pass valid slug | configured BrainAtom | unit |
| discover all models | `getBrainAtomsByTogetherAI()` | call function | array of 20 atoms | unit |
| use new cheap model | `genBrainAtom({ slug: 'together/lfm2/24b' })` | invoke .ask() | response with metrics | integration |
| use new frontier model | `genBrainAtom({ slug: 'together/deepseek/v4-pro' })` | invoke .ask() | response with metrics | integration |
| tool use on new model | `genBrainAtom({ slug: 'together/kimi/k2.6' })` | invoke .ask() with tools | tool calls returned | integration |

## journey test sketches

### journey 1: select and use new model

```
given('[case1] developer selects new frontier model')
  when('[t0] genBrainAtom called with together/deepseek/v4-pro')
    then('returns BrainAtom instance')
    then('slug is together/deepseek/v4-pro')
    then('spec.gain.grades.swe is 80.6')
  when('[t1] atom.ask called with prompt')
    then('response contains output')
    then('metrics includes token counts')
    then('metrics includes cash costs')
```

| step | action | user sees |
|------|--------|-----------|
| t0 | call genBrainAtom | BrainAtom with correct spec |
| t1 | call atom.ask | response with output and metrics |

### journey 2: discover all available models

```
given('[case1] developer discovers catalog')
  when('[t0] getBrainAtomsByTogetherAI called')
    then('returns array with 20 atoms')
    then('includes new slugs like together/lfm2/24b')
    then('includes new slugs like together/deepseek/v4-pro')
```

## critical paths
