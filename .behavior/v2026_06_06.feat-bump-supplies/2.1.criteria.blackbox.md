# 2.1.criteria.blackbox

## usecase.1 = select model by slug

```
given('a developer imports genBrainAtom')
  when('they pass a valid slug')
    then('they receive a configured brain atom')
      sothat('they can invoke the model without further setup')
    then('the brain has accurate cost specs')
      sothat('they can estimate expenses before inference')
    then('the brain has accurate capability specs')
      sothat('they can verify the model fits their usecase')

  when('they pass an invalid slug')
    then('typescript rejects at compile time')
      sothat('typos and outdated slugs are caught before runtime')
```

## usecase.2 = choose model for budget constraints

```
given('a developer needs the cheapest option')
  when('they review available slugs')
    then('they find lfm2/24b at $0.03/$0.12 per 1M tokens')
      sothat('they can run high-volume triage at minimal cost')
    then('they find gpt-oss/20b at $0.05/$0.20 per 1M tokens')
      sothat('they have an alternative ultra-cheap option')

given('a developer needs best value (quality per dollar)')
  when('they review available slugs')
    then('they find minimax/m2.5 at $0.30/$1.20 with 80.2% swe-bench')
      sothat('they get frontier code quality at budget prices')
```

## usecase.5 = access model specs programmatically

```
given('a developer has instantiated a brain')
  when('they access brain.spec.cost.cash.input')
    then('they receive the per-token input cost')
  when('they access brain.spec.cost.cash.output')
    then('they receive the per-token output cost')
  when('they access brain.spec.gain.size.context.tokens')
    then('they receive the context window size')
  when('they access brain.spec.gain.grades.swe')
    then('they receive the swe-bench score (if available)')
      sothat('they can compare models programmatically')
```

## usecase.6 = handle model updates

```
given('a model price changes on together.ai')
  when('the package releases a new version')
    then('the updated prices are reflected in specs')
      sothat('cost estimates remain accurate')

given('a model is removed from together.ai')
  when('the package releases a new version')
    then('the slug is removed from the type union')
    then('code that references the old slug fails to compile')
      sothat('developers are forced to migrate explicitly')
```
