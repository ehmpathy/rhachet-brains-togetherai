# 3.1.1.research.external.product.claims

## model performance claims

### [FACT] frontier open-source models match proprietary on code benchmarks

> "GLM-4.7 (Thought mode) achieves 89% on LiveCodeBench, matched to GPT-5 on code tasks" [1]

> "the gap between top open-source models and proprietary US models has narrowed considerably since 2024" [1]

sources: [1][2][3]

**convergence:** 3+ sources agree open-source now trails by only 5-7 quality index points

---

### [FACT] swe-bench verified vs pro scores are not comparable

> "Claude Opus 4.5 scores 80.9% on SWE-bench Verified but scores 45.9% on SWE-bench Pro" [4]

> "SWE-Bench Verified has 500 Python-only tasks with small fixes (median 4 lines), while SWE-Bench Pro has 1,865 multi-language tasks that require substantial, multi-file modifications (average 107 lines across 4.1 files)" [4]

> "OpenAI stopped reports on Verified scores in early 2026 and now recommends SWE-bench Pro instead" [5]

**implication:** 80% verified ≈ 45% pro. our models track verified scores; pro comparisons require ~35 point adjustment.

sources: [4][5][6]

---

### [FACT] deepseek v4 pro and minimax m2.5 are frontier-competitive

> "MiniMax M2.5 achieves 80.2% on SWE-bench as an open-weight model, while DeepSeek V4 Pro currently leads on published benchmarks like SWE-bench (80.6%)" [7]

> "Six models now score within 0.8 points of each other on SWE-bench Verified" [7]

sources: [7][8]

---

## cost claims

> "LLM API rates in 2026 span a 600x range, from $0.10/MTok (GPT-4.1 Nano) to $60/MTok output (o3)" [9]

sources: [9][10]

---

### [FACT] costs trend down 30-50% per year

> "Prices trend down 30-50% per year since 2023" [9]

> "Google's Gemini 3.1 Flash costs $0.10 per million input tokens and $0.40 per million output tokens, which is a 99.7% price reduction in three years" [9]

sources: [9][10][11]

industry assumes together.ai rates may differ from direct API rates but offer unified access and reliability.

no explicit update cadence found. rates may change without notice.

## benchmark claims

### [FACT] swe-bench verified is considered contaminated

> "OpenAI's audit found that all frontier models are contaminated on Verified" [5]

> "59.4% of hard tasks have flawed tests" [5]

sources: [5][6]

---

### [OPIN] swe-bench verified still useful for relative comparison

despite contamination concerns, verified scores remain widely reported and useful for model comparison within the same evaluation window.

sources: [4][6]

---

## model architecture claims

### [FACT] moe architectures dominate cost-efficient inference

> "DeepSeek V4 Pro: 1.6T parameter (49B activated) MoE" [12]

> "Kimi K2.6: 1T parameter (32B activated) MoE" [13]

> "GLM-5.1: 754B parameter (40B activated) MoE" [14]

all frontier models use sparse MoE to reduce inference cost.

sources: [12][13][14]

---

### [FACT] lfm2 uses hybrid architecture with 2B active params

> "LFM2-24B-A2B is Liquid AI's largest LFM2 model, a sparse Mixture of Experts (MoE) model with 24 billion total parameters with 2 billion active per token" [15]

sources: [15]

---

## tool use claims

### [KHUE] which new models support tool/function calls?

requires per-model verification. together.ai docs indicate tool support varies by model.

---

### [SUMP] all chat models support basic tool use

not confirmed. cheap models (lfm2, gpt-oss) may lack tool support.

## context window claims

### [FACT] deepseek v4 pro supports 1M context

> "DeepSeek V4 Pro supports a cost-effective 1M context length" [16]

> "the context window is 1,048,576 tokens with a maximum output of 384,000 tokens" [16]

sources: [16][17]

**conflict:** together.ai model page shows 512K [12], deepseek docs show 1M [16]. together.ai may truncate.

---

### [FACT] lfm2 context is 32K not 128K

> "LFM2-24B-A2B: 32,768 token context" [15]

vision document stated 128K — correction required.

---

## anti-patterns

### sources [9][10][11] warn against:

- hard-coded rates without version control
- not budget for 30-50% annual price drops
- assume benchmark scores are static (they improve with each model generation)
