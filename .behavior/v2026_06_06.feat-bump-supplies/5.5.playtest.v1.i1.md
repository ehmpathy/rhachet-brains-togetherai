# playtest: rhachet-brains-togetherai serverless model catalog

## prerequisites

- node.js 20+
- TOGETHER_API_KEY set in environment (run `rhx keyrack unlock --owner ehmpath --env test`)
- repo cloned and dependencies installed (`pnpm install`)
- build completed (`npm run build`)

## sandbox

- all file operations target `@gitroot/.temp/`
- no repo pollution outside sandbox

---

## happy paths

### 1. build succeeds

```bash
npm run build
```

**pass if:** exit code 0, no errors
**fail if:** typescript errors or build failure

### 2. verify atom count is 14

```bash
node -e "
const { getBrainAtomsByTogetherAI } = require('./dist/contract/sdk/index.js');
const atoms = getBrainAtomsByTogetherAI();
console.log('atom count:', atoms.length);
console.log('slugs:', atoms.map(a => a.slug).join(', '));
"
```

**pass if:** output shows `atom count: 14` and lists all slugs
**fail if:** count differs from 14 or errors occur

### 3. verify cheap model exists (lfm2/24b)

```bash
node -e "
const { genBrainAtom } = require('./dist/domain.operations/atom/genBrainAtom.js');
const atom = genBrainAtom({ slug: 'together/lfm2/24b' });
console.log('slug:', atom.slug);
console.log('input cost:', atom.spec.cost.cash.deets.input);
console.log('output cost:', atom.spec.cost.cash.deets.output);
"
```

**pass if:**
- slug is `together/lfm2/24b`
- input cost is $0.03 per 1M tokens ($0.00000003 per token)
- output cost is $0.12 per 1M tokens ($0.00000012 per token)

**fail if:** slug not found or costs differ

### 4. verify frontier model exists (deepseek/v4-pro)

```bash
node -e "
const { genBrainAtom } = require('./dist/domain.operations/atom/genBrainAtom.js');
const atom = genBrainAtom({ slug: 'together/deepseek/v4-pro' });
console.log('slug:', atom.slug);
console.log('swe-bench:', atom.spec.gain.grades.swe);
console.log('context:', atom.spec.gain.size.context.tokens);
"
```

**pass if:**
- slug is `together/deepseek/v4-pro`
- swe-bench is 80.6
- context is 512000

**fail if:** slug not found or specs differ

### 5. invoke model and receive response

```bash
node -e "
const { genBrainAtom } = require('./dist/domain.operations/atom/genBrainAtom.js');
const { z } = require('zod');

(async () => {
  const atom = genBrainAtom({ slug: 'together/qwen3/235b' });
  const result = await atom.ask({
    role: { briefs: [] },
    prompt: 'respond with exactly: hello world',
    schema: { output: z.object({ content: z.string() }) },
  });
  console.log('output:', result.output.content);
  console.log('tokens.input:', result.metrics.size.tokens.input);
  console.log('tokens.output:', result.metrics.size.tokens.output);
})();
"
```

**pass if:**
- output contains "hello" (case insensitive)
- tokens.input > 0
- tokens.output > 0

**fail if:** no response, error, or zero tokens

### 6. verify all 14 slugs are exported

```bash
node -e "
const { getBrainAtomsByTogetherAI } = require('./dist/contract/sdk/index.js');
const atoms = getBrainAtomsByTogetherAI();
const expected = [
  'together/qwen3/235b',
  'together/qwen3.5/9b',
  'together/qwen3.5/397b',
  'together/qwen3.6/plus',
  'together/qwen3.7/max',
  'together/deepseek/v4-pro',
  'together/kimi/k2.6',
  'together/llama3.3/70b',
  'together/glm/5',
  'together/glm/5.1',
  'together/gemma4/31b',
  'together/lfm2/24b',
  'together/gpt-oss/20b',
  'together/gpt-oss/120b',
];
const actual = atoms.map(a => a.slug).sort();
const absent = expected.filter(s => !actual.includes(s));
const extra = actual.filter(s => !expected.includes(s));
console.log('expected:', expected.length);
console.log('actual:', actual.length);
console.log('absent:', absent.length ? absent : 'none');
console.log('extra:', extra.length ? extra : 'none');
"
```

**pass if:**
- expected: 14
- actual: 14
- absent: none
- extra: none

**fail if:** any slug is absent or extra slugs appear

## edge paths

```bash
mkdir -p .temp
cat > .temp/test-invalid-slug.ts << 'EOF'
import { TogetherBrainAtomSlug } from '../src/domain.operations/atom/BrainAtom.config';
const slug: TogetherBrainAtomSlug = 'together/invalid/model';
EOF
npx tsc .temp/test-invalid-slug.ts --noEmit --skipLibCheck 2>&1 || true
```
