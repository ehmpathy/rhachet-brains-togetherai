# 3.1.1.research.external.product.domain.terms.v1

## summary

**no new domain terms required.**

this wish adds entries to an extant catalog — no new domain objects, entities, or operations.

---

|------|------|---------|

## why no new terms?

the extant domain structure handles the wish:

1. **catalog pattern already established** — CONFIG_BY_ATOM_SLUG is a static map
2. **slug format already standardized** — `together/{org}/{model}` covers all additions
3. **BrainSpec already supports all required fields** — swe grades, context, rates, tool use

no structural changes required. only data additions.

---

## parallel concept: product catalog

like a parts catalog in a factory:

| domain | catalog | entry | lookup |
|--------|---------|-------|--------|
| factory | part catalog | part config | part number |
| culinary | ingredient list | ingredient spec | item code |

the pattern is well-established. no innovation needed.
