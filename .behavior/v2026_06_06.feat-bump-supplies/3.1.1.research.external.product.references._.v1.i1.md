## convergence signals

### 3+ sources agree: swe-bench verified vs pro are different benchmarks
sources [17][18][19][20] converge:
- verified: 500 python tasks, small fixes
- pro: 1,865 multi-language tasks, larger changes
- ~35 point score difference between same model

### 3+ sources agree: exponential backoff for rate limits
sources [6][24][18] recommend exponential backoff for 429 errors

### 3+ sources agree: cost trends down 30-50% annually
sources [21][22][23] note consistent price reductions

### conflict: context window sizes
- deepseek v4 pro: together.ai shows 512K [7], deepseek docs show 1M [external]

### conflict: swe-bench score types
- some sources report verified scores, others pro scores
- resolution: document which benchmark for each model

## anti-patterns

sources [21][24][25] warn against:
- hard-coded rates without version control
- burst traffic patterns that trigger rate limits
- agents with overly broad tool permissions
- no exponential backoff
- assume benchmark scores are static
