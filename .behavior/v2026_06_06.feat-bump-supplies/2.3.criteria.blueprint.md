## subcomponent contracts

```
given('TogetherBrainAtomSlug type')
  then('is a union of all valid model slugs')
  then('includes new slugs: lfm2/24b, gpt-oss/20b, qwen3.5/9b, gemma4/31b')
  then('includes new slugs: minimax/m2.5, minimax/m2.7, qwen3.5/397b')
  then('includes new slugs: deepseek/v4-pro, kimi/k2.6, glm/5.1')
  then('invalid slugs fail typescript compilation')

given('CONFIG_BY_ATOM_SLUG map')
  then('maps each slug to a BrainAtomConfig')
  then('each config contains: model id, description, spec')
  then('spec.cost.cash contains: input and output rates per token')
  then('spec.gain.size.context.tokens contains: context window')
  then('spec.gain.grades.swe contains: swe-bench score (where available)')

given('genBrainAtom function')
  then('accepts { slug: TogetherBrainAtomSlug }')
  then('returns configured BrainAtom with spec from CONFIG_BY_ATOM_SLUG')
```

## composition boundaries

```
given('model catalog implementation')
  then('slug type union is source of truth for valid models')
  then('CONFIG_BY_ATOM_SLUG implements all slugs in the union')
  then('genBrainAtom composes slug lookup with brain instantiation')
```

```
given('new model additions')

  then('has integration test: genBrainAtom returns valid brain for each new slug')

given('price update (llama3.3/70b)')
  then('has unit test: verify updated cost values')
```
